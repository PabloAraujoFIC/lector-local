# Instaladores

Usar `scripts/release.py`: salidas oficiales bajo `release/desktop/`. No compartir entornos .venv, runtimes intermedios ni antiguos instaladores con pesos incluidos. El escritorio registra el host al abrirse; Windows lo registra además desde el instalador y lo retira al desinstalar.

Véase `docs/RELEASE.md` para construcción y `docs/TESTERS.md` para instalación por sistema y navegador.
