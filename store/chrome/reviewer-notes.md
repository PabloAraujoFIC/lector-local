# Instrucciones para revisión

1. Instalar el escritorio del mismo número de versión. Abrirlo y descargar Piper (77 MB) o Kokoro (354 MB) en Ajustes, aceptando la descarga.
2. Instalar la extensión. La aplicación registra Firefox automáticamente si existe el perfil. Chromium requiere el ID asignado a esta ficha: introducirlo en Ajustes > Escucha desde tu navegador y registrar.
3. Abrir un artículo de Wikipedia, elegir Leer artículo o seleccionar texto y elegir Leer selección. Verificar voz, pausa/reanudación, detener y párrafos.
4. Desconectar la red: el texto se lee igual. Para comprobar el error de host ausente, retirar temporalmente el registro en un perfil de prueba.

Los títulos y el texto elegido se transmiten por Native Messaging exclusivamente a un proceso del mismo dispositivo. No se transmiten URLs. Las descargas HTTPS de modelos son iniciadas por el usuario en el escritorio, sin incluir su texto. No hay cuentas ni telemetría. No hay versión Android.

La firma de tiendas y los certificados de escritorio están pendientes: SIGNING_REQUIRED. El proveedor debe suministrar enlaces de descarga accesibles antes de enviar a revisión.
