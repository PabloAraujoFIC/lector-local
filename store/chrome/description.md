# Lector Local

Descripción corta: Escucha selecciones y artículos con el motor TTS de tu dispositivo.

Descripción completa: Lee artículos y texto seleccionado con voces ejecutadas en tu ordenador. Pausa, reanuda y cambia de párrafo desde el popup o el menú contextual. La extracción se realiza localmente y se activa cuando solicitas leer una página. Requiere instalar la aplicación de escritorio Lector Local y descargar una voz desde Ajustes una vez. Después, la lectura funciona sin conexión. El texto y el audio no se envían a servicios de voz, ni se utilizan para publicidad. Disponible para Windows, macOS y Linux según los instaladores publicados.

Categoría propuesta: Productividad. Idioma: español.

Antes de enviar: publicar una URL HTTPS accesible para la política de privacidad, proporcionar correo de soporte y enlaces públicos a instaladores. El repositorio actual es privado; no sirve como enlace accesible a usuarios o revisores.
